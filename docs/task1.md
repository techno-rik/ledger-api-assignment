# Task 1 – Kubernetes Hardening

## Objective

Deploy the Ledger API on Kubernetes following security and production best practices.

## Implemented

- Namespace isolation
- ConfigMap
- Secret
- ServiceAccount
- RBAC (Role & RoleBinding)
- Deployment with 3 replicas
- ClusterIP Service
- Ingress
- NetworkPolicy
- Resource Requests & Limits
- SecurityContext
- Liveness Probe
- Readiness Probe

## Result

The application was successfully deployed to the Kind cluster with all security controls applied.
